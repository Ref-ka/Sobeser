# Sobeser

Консольная мультиагентная система для проведения технического интервью.

## На чем работает

Для реализации агентов используется LangChain, для построения связей между агентами используется граф из LangGraph.

LLM вызывается через OpenAI-совместимый API [VseGPT](https://vsegpt.ru) (`https://api.vsegpt.ru/v1`). Модель задаётся в `config.py` (`Config.model_name`, по умолчанию `google/gemini-3-flash-pre-thinking`).

### Как устроен граф

```
START ─┬─(плана ещё нет)─> Planner ─> Observer
       └─(план есть)──────────────> Observer ─┬─> Interviewer ─> END (ждём ответ кандидата)
                                              └─> Manager ─────> END (интервью завершено)
```

Граф запускается заново на каждый ответ кандидата. Planner срабатывает один раз — при генерации первого вопроса.

### Роли (агенты)

- **Planner** (`nodes/planner_node.py`)
  - Составляет план интервью, основываясь на данных кандидата.
- **Observer** (`nodes/observer_node.py`)
  - Анализирует последний ответ кандидата.
  - Решает, завершать интервью или продолжать (ответ, начинающийся с `finished`, завершает интервью — например, когда пройден весь план).
  - Регулирует сложность вопросов по шкале 1–5 (стартовый уровень — 2).
- **Interviewer** (`nodes/interviewer_node.py`)
  - Генерирует следующий вопрос кандидату, опираясь на:
    - план интервью,
    - текущую сложность,
    - последнюю оценку Observer,
    - последние 6 сообщений диалога.
  - Именно его текст показывается пользователю во время интервью.
- **Manager** (`nodes/manager_node.py`)
  - Формирует финальный структурированный фидбэк.
  - Перед генерацией суммаризирует мысли Observer.
  - Если задан `TAVILY_API_KEY`, использует веб-поиск Tavily для подбора материалов по пробелам в знаниях.

## Требования

- Python 3.12+ (в коде используются f-строки с `
` внутри выражений, на более старых версиях будет `SyntaxError`)
- Зависимости из `requirements.txt`
- Ключ(и) API:
  - **обязательно**: `VSEGPT_API_KEY`
  - **опционально**: `TAVILY_API_KEY` (если хотите, чтобы Manager подбирал ссылки через веб-поиск)

## Установка

1) Создайте и активируйте виртуальное окружение.

2) Установите зависимости:

```bash
pip install -r requirements.txt
```

## Настройка окружения (.env)

В проекте используется `python-dotenv`: переменные автоматически подхватываются из файла `.env` в корне.

Создайте `.env` рядом с `main.py`:

```env
VSEGPT_API_KEY=ваш_ключ_vsegpt
TAVILY_API_KEY=ваш_ключ_tavily
```

## Запуск

```bash
python main.py
```

Дальше:

- введите профиль кандидата (или нажимайте Enter, чтобы оставить значения по умолчанию);
- дождитесь первого вопроса;
- вводите ответы — ввод многострочный, завершайте его отдельной строкой `--stop--` (или EOF: `Ctrl+Z`, затем `Enter` в Windows / `Ctrl+D` в Linux и macOS).

## Управление интервью

- **Чтобы завершить интервью и получить фидбэк**, напишите в ответе одно из ключевых слов: `стоп`, `фидбэк`, `хватит`, `заверши`, `закончи`, `давай фидбэк`, `хочу завершить`, `завершить интервью`, `закончить интервью`, `стоп интервью`.
  - Проверяется вхождение подстроки без учёта регистра, поэтому интервью завершится и от обычного ответа, где встречается такое слово, например «транзакция завершится» или «стопка вызовов».
- `Observer` может сам завершить интервью, если кандидат ответил на последний вопрос плана или явно попросил закончить.
- **`Ctrl+C`** прерывает интервью без финального фидбэка; программа спросит, сохранить ли лог (`y/n`).

## Логи

После завершения сессии (или после `Ctrl+C` с ответом `y`) в `./logs/` сохраняются файлы:

- `interview_log_YYYY-MM-DD_HH-MM-SS.json`
  - `participant_name` — имя участника (задаётся в `logger.py`, из профиля кандидата не берётся).
  - `turns[]` содержит:
    - `agent_visible_message` — что говорил интервьюер,
    - `user_message` — ответ кандидата,
    - `internal_thoughts` — внутренние сообщения/оценки агентов (скрытая рефлексия).
  - `final_feedback` — финальный отчёт Manager.
- `runtime_traces.jsonl`
  - построчные JSON-события по выполнению узлов (`planner/observer/interviewer/manager`), длительности и ошибкам.
  - Перезаписывается при каждом запуске.

## Структура проекта

- `main.py` — CLI-приложение и цикл диалога.
- `config.py` — загрузка `.env`, API-ключи и имя модели.
- `interview_engine.py` — создание агентов, сборка графа LangGraph, обработка ввода, логирование.
- `nodes/` — узлы графа:
  - `planner_node.py`
  - `observer_node.py`
  - `interviewer_node.py`
  - `manager_node.py`
- `prompts.py` — системные промпты ролей.
- `routing.py` — условия переходов между узлами.
- `state.py` — схема состояния `AgentState`.
- `logger.py` — сохранение логов сессии и runtime-трейсов.
- `summarizer.py` — суммаризация мыслей Observer перед финальным фидбэком.
